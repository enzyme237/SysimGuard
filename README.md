# Sysim Guard

EDR mobile open source pour Android, destiné aux particuliers.
Détection d'applications malveillantes par un modèle de Machine Learning
exécuté entièrement sur l'appareil, sans envoi de données.

**Statut :** prototype en développement, réalisé dans le cadre d'un mémoire
de fin d'études (Mastère Cybersécurité & Cloud, IPSSI).
